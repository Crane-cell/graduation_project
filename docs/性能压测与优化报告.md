## 3. 优化前定位（cProfile，2000 次整队决策，MADDPG）

```
ncalls   tottime  cumtime  function
72000/12000  0.050  0.538  torch.nn.modules.module.py:_wrapped_call_impl   ← 模块分发
 36000      0.211  0.211  torch._C._nn.linear                            ← 真实矩阵乘
 24000      0.052  0.052  torch.relu
总耗时 0.724s（2000 次）
```

**结论**：真正矩阵乘仅 0.21s（29%），**模块分发开销 0.54s（74%）**——6 个同构 MLP × 每层 × 每次决策都要走 `nn.Module.__call__` 的 Python 分发链。这就是优化点：**整队批量前向**。

## 4. 优化实现（batch_mlp_forward）

`src/algorithm/networks.py` 新增 `batch_mlp_forward(x, modules)`：把 n 个**同构 MLP**的逐层权重堆叠成 `(n, out, in)`，一次 `torch.bmm` 算一整层，全部智能体 3 层只需 3 次 bmm；`MADDPG/QMIX/IQL` 覆写 `select_actions_batch` 使用之（`BaseAlgo` 新增批量契约，默认回退逐智能体循环，行为不变）。语义等价性由单元测试 `test_batch_matches_loop_epsilon_zero`（三算法、ε=0 动作逐位一致）与 `test_batch_mlp_forward_matches_loop`（allclose 1e-5）保证。

## 5. 优化前后真实对比（同机同轮，场景 B，2000 次整队决策）

| 算法 | loop（优化前） | batch（优化后） | 提升 |
| --- | --- | --- | --- |
| MADDPG | 0.320 ms / 3126 次/s | **0.233 ms / 4288 次/s** | **-27.2%** |
| QMIX | 0.328 ms / 3052 次/s | **0.246 ms / 4064 次/s** | **-25.0%** |
| IQL | 0.311 ms / 3216 次/s | **0.220 ms / 4551 次/s** | **-29.3%** |

优化后 cProfile（同一 2000 次）：模块分发 72k 次调用（0.538s）消失，热点收敛为 `batch_mlp_forward`（0.503s cum 单函数）内的 `torch.stack`×12000 + `torch.bmm`×6000——结构性好转，剩余 stack 开销可进一步权重预堆叠缓存消除（留作 M2 训练阶段优化项）。

## 8. 结论与遗留

1. **判定：通过**——批量前向优化真实有效（三算法 25%—29%），NF-01 余量充足，84/84 用例回归全绿（含 2 条新增等价性用例）。
2. **优化方法归纳**：测量驱动 → cProfile 定位 Python 分发瓶颈 → 权重堆叠 bmm 批量前向 → 等价性测试锁语义 → 回归验证。此方法论已写入交付物。
3. **遗留与后续**：
   - GPU 推理迁移（tensor.to(cuda)）列入 M2 训练阶段（本轮基准基于 CPU 张量，CUDA torch 已就绪）
   - 权重堆叠缓存（消除 stack 开销）列为 M3 优化项
   - 场景 A 数字含更新成本，报告未拆分（拆分工具 M4 实验阶段补充）
