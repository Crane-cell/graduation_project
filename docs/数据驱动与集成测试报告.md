## 2. 配置三段式校验（config.py）

`load_config(path)` = **读取** → `validate_config()` = **校验 + 兜底 + 告警**：

1. **校验**：类型（int/float/bool/str）、数值范围（闭区间）、允许集合（算法名枚举）
   —— 违例**抛 ValueError 并列出全部明细**（含字段名），绝不静默；
   整数域兼容整值浮点（`3.0` ≡ `3`），布尔域兼容 `0/1`
2. **兜底**：缺失字段用 `DEFAULTS` 补齐（同源口径默认值），实验可只写差异字段
3. **告警**：未知字段（顶层/段/子段）聚合为一条 `UserWarning`，防拼写错误被静默吞掉

规则表（`_RULES`）覆盖 5 段 33 个字段：env（场地/球门/奖励权重）、algorithm（超参+消融）、train、eval、logging；与 `default.yaml` 保持同源口径（文件头注释已注明双向同步要求）。

## 3. 检查点版本兼容（checkpoint.py）

- `SCHEMA_VERSION = 1`；`save()` 落盘时注入 `schema_version` + `saved_at` + `global_step` 元信息
- `load()` 版本策略：**v0 旧档**（无版本字段）→ 兜底字段并告警、可续训；**v1** → 直接读；**v>1** 未来档 → `ValueError` 拒绝（防静默误读未来格式）
- **断点续训语义**（已验证）：`total_steps` 为绝对预算，续训时把 `trainer._global_step` 置为存档步数、传入原始总预算即可继续
