## 1. 项目概述与范围边界

本系统基于 PettingZoo 多智能体环境接口规范**自研轻量 2D 足球仿真环境**（实证发现 pettingzoo 1.27.0 无内置足球环境，见 QA 表 Q7；仿真环境建模恰为任务书①的核心工作），在其对抗场景中基于 CTDE（集中式训练、分散式执行）框架实现 MADDPG 与 QMIX 两种多智能体强化学习算法，训练具备角色分工的协作策略，并以 IQL 独立学习策略与规则基线为对照开展对抗评估。

**范围边界 / 明确不做（F22）**：真实机器人硬件部署与真机实验；3D 仿真环境；RoboCup 2D 平台主线开发（仅作为后期扩展验证）；图形化游戏界面包装；分布式多机训练；超过 11v11 的场景规模；人工实时操控对局。（来源：任务书范围 + 开题报告 5.2）

## 2. 术语表

| 术语 | 定义 |
| --- | --- |
| 智能体 | 足球仿真中的一个决策主体（球员），具备局部观测与动作输出 |
| 观测（Observation） | 智能体可感知的环境状态编码（自身运动状态、球的位置速度、可见队友/对手相对信息、角色标识） |
| 动作（Action） | 智能体对环境的指令（移动方向分档、踢球方向×力度分档，统一离散化） |
| 奖励（Reward） | 环境对智能体行为的标量反馈，含团队稀疏奖励与个体塑形奖励 |
| 转移（Transition） | 一次决策的四元组（观测，动作，奖励，下一观测） |
| 经验回放（Replay Buffer） | 存储历史转移供网络更新重复采样的缓冲区 |
| CTDE | Centralized Training with Decentralized Execution，集中式训练、分散式执行 |
| MADDPG | Multi-Agent Deep Deterministic Policy Gradient，集中式评论家 + 分散式演员 |
| QMIX | 基于单调性约束混合网络的值分解算法 |
| IQL | Independent Q-Learning，各智能体独立学习的基线算法 |
| 信用分配（Credit Assignment） | 将团队奖励分解为个体贡献的机制 |
| 塑形奖励 | 为引导协作行为设计的密集个体奖励项（控球、传球、拦截、跑位） |
| 课程学习 | 由 3v3 小场景到 11v11 全场的递进训练策略 |
| episode | 一局完整对抗（从重置到对局结束） |
| checkpoint | 训练过程的网络参数与状态存档，用于恢复续训 |
| 决策周期 | 智能体完成一次"观测→决策"的时间，本系统推理指标即按此口径 |

## 3. 用户与角色

| 角色 | 类型 | 职责 |
| --- | --- | --- |
| 研究者 | 人类用户 | 编写/修改配置，启动训练与评估，查看曲线与报告，分析实验结果 |
| 训练调度器 | 系统角色 | 驱动"采集→更新"循环、按策略推进 episode、触发评估与保存（无人类交互） |
| 评估器 | 系统角色 | 按固定协议执行对抗对局并统计指标 |
| 足球仿真环境（自研组件，PettingZoo API 兼容） | 外部组件 | 提供物理仿真、规则判定与观测/动作空间（环境建模为任务书①交付内容） |

## 5. 用户故事

1. 作为研究者，我希望只用一份 YAML 配置就能定义网络尺寸、学习率与奖励权重，以便不改代码即可开展对比实验（对应 F05）。
2. 作为研究者，我希望一条命令即可启动 3v3 场景训练并自动产出 TensorBoard 曲线，以便随时判断收敛情况（对应 F09、F18）。
3. 作为研究者，我希望训练自动保存 checkpoint 并能从断点恢复续训，以便中断后不丢失训练进度（对应 F10）。
4. 作为研究者，我希望固定种子下两次运行产生完全一致的轨迹，以便实验结果可信可对比（对应 F09、NF-02）。
5. 作为研究者，我希望在配置中一键切换 MADDPG / QMIX / IQL，以便三种算法在同一评估协议下公平对比（对应 F06/F07/F08/F12、F13）。
6. 作为研究者，我希望评估输出胜率、净胜球、平均团队奖励、推理耗时四项指标并生成报告表，以便直接支撑论文实验章节（对应 F13）。

## 8. 验收标准（Given-When-Then）

> 全部 P0 均有可判定验收标准；模糊词（流畅/合理/快速/良好等）零容忍。

| # | 功能 | Given | When | Then |
| --- | --- | --- | --- | --- |
| 1 | F01 环境封装 | 配置指定 3v3 soccer 场景、种子 42 | 调用 reset() | 返回 6 个智能体的初始观测，形状与配置一致；同种子两次 reset 观测逐元素相等 |
| 2 | F02 观测编码 | 一局进行中的环境状态 | 读取任一智能体观测 | 张量形状为 (obs_dim,)，每个元素取值在 [-1, 1] 区间内 |
| 3 | F03 动作接口 | 环境处于运行态 | 提交合法动作索引 a ∈ [0, A) | 环境正常推进且不抛异常；提交越界索引时抛出带索引信息的明确异常 |
| 4 | F04 奖励计算 | 配置 goal_reward=10，发生进球事件 | 计算该步奖励 | 得分方团队奖励 = +10 + Σ(塑形项×权重)，失球方 = -10 + Σ(塑形项×权重) |
| 5 | F05 配置外置 | YAML 中 lr 由 0.001 改为 0.005 | 重启训练脚本 | 加载日志输出 lr == 0.005，且本次运行未修改任何 .py 文件 |
| 6 | F06 智能体网络 | batch=32 的合法观测张量 | 执行一次前向传播 | 输出形状为 (32, A)，且无 NaN / Inf |
| 7 | F07 MADDPG | 固定种子、同一批采样转移 | 执行一次 update | 损失值为有限数；演员与评论家参数均发生变化 |
| 8 | F08 QMIX | 固定种子、同一批采样转移 | 执行一次 update | TD 损失为有限数；个体 Q 网络与混合网络参数均发生变化 |
| 9 | F09 训练主循环 | 相同种子、相同配置运行两次，各 5 个 episode | 对比两次的环境转移序列 | 逐 episode、逐步完全一致（可复现） |
| 10 | F10 检查点存取 | 训练 1000 步后保存并从 checkpoint 恢复 | 继续训练并读取网络参数 | 续训起点参数与保存时逐元素一致；TensorBoard 曲线连续 |
| 11 | F13 对抗评估 | 已收敛策略与 IQL 基线各一份 | 运行 1000 局固定种子评估 | 输出胜率、净胜球均值、平均团队奖励、推理耗时分位数四项指标 |
| 12 | F18 曲线可视化 | 完成一次训练 | 打开 TensorBoard 面板 | 损失/奖励/胜率标量曲线完整可读 |
